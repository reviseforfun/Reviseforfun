# 📚 ReviseForFun

> Make Studying Actually Fun! A free, beautiful revision tool built with vanilla HTML, CSS, and JavaScript.

## ✨ Features

- 🎴 **Smart Flashcards** - Create, organize, and study flashcards by subject
- 🧠 **Interactive Quizzes** - Auto-generated quizzes from your flashcards
- 📝 **Study Notes** - Write and organize rich study notes
- ⏱️ **Pomodoro Timer** - Stay focused with timed study sessions
- 📊 **Progress Tracking** - Activity heatmap, streaks, and statistics
- 🌙 **Dark Mode** - Easy on the eyes for late-night studying
- 💾 **Local Storage** - All data saved in your browser, no account needed
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile

## 🚀 Getting Started

1. Fork this repository
2. Go to **Settings → Pages**
3. Under **Source**, select **main** branch
4. Your site will be live at `https://yourusername.github.io/reviseforfun/`

## 🛠️ Tech Stack

- Pure HTML5, CSS3, JavaScript (ES6+)
- No frameworks or dependencies
- CSS Custom Properties for theming
- LocalStorage for data persistence
